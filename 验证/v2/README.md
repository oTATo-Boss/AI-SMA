## 真实技能安装

见 [clean-install.json](clean-install.json)。从声明的公开固定 Git 提交获取完整包，复制到新的隔离用户目录，保留包内资源、权限和许可，建立 Claude 发现入口，再运行真实逐文件验证。

九类默认项目的技能文件均验证通过。此实验未更改真实 HOME，未复用作者共享技能文件；宿主运行工具和登录状态另行处理。安装验证不等于所有生成服务或模型就绪。

四个新通用方法和跨平台生图桥已在 my-skills 发布。四个方法已真实安装到作者共享库并建立 Claude 入口。Anime.js 的公开适配版本已发布，作者原有同名本地改编被保留，没有为了检查通过而覆盖独立修改。

## 四类媒体小样

[创作简报](production/BRIEF.md)、[分镜](production/STORYBOARDS.md)、[源工程](production/render_samples.py)、[技术报告](production/reports/media-verification.json)、[独立审查](production/reports/independent-review.md)。

- 科普 60 秒：中文旁白、月相解释、动画和字幕。
- 广告 15 秒：原创虚构笔记本的横屏、竖屏两版。
- 连续剧情：两个约 30 秒段落，稳定角色袖口、道具和场景；另做一个镜头的局部修订，保留旧版本与未改镜头证据。
- MV 30 秒：原创音乐、四个视觉段落、节奏动画与混音。

全部为真实 H.264/AAC 媒体，已验证尺寸、时长、全量解码、音频信号、字幕时间和帧状态可重复。实际检查了接触表、额外原片帧及修复对照；科普的受光方向问题已经修正并复核指定时间点。

**连续播放的主观连贯性与实际试听仍未完成。** 当前模型不接收音频输入；信号测量没有被当作试听。本次是代码动画制作与方法验证，不声称四种完整角色工作流都已端到端跑通，也不代表商业级成片验收。五种其他模板仅结构验证。

本机查看 `production/review.html` 可播放输出；媒体位于其相邻 outputs 目录并被 Git 忽略。包含系统语音的内部验证媒体不公开分发，其他电脑重现时提供可用且获授权的音频/字体，或按脚本说明仅做本机私用试验。
