# 规范 · 长期依据

每份文件只维护自己的职责，按任务路由读取（根目录 `AGENTS.md`），不需要全部通读。事实、方向和知识放在这里，不等于都是强制规则。

| 文件 | 唯一职责 |
|---|---|
| [项目规则](项目规则.md) | 细则：职责、目录与权限、任务与授权、技能使用、记录 |
| [账号信息](账号信息.md) | 本人、品牌、产品和账号的事实；指标引用账号数据 |
| [定位与策略](定位与策略.md) | 目标、受众、内容方向、变现、业务测试和待决问题 |
| [内容与交付](内容与交付.md) | 品牌、声音、制作、包装、分发检查和验收标准 |
| [账号配置](账号配置.yaml) | 规格参数：画幅、封面、声音、生成默认值、交付命名、时区；也是 social-media 技能读取的项目配置 |
| [选题池](选题池.md) | 候选想法、来源和已立项任务的链接，不维护任务进度 |
| [偏好与经验](偏好与经验.md) | 长期偏好、反馈、经验和教训 |
| [外部知识](外部知识.md) | 有出处和日期的外部资料，推测保留待验证标记 |

执行方法见 [SOP](../sop/README.md)，原始数据和正式报告见 [账号数据](../账号数据/README.md)，任务状态见 [任务总览](../log/任务总览.md)，资源位置见 [附录](../附录/README.md)。目录结构和权限见项目规则第 2 节。
