# 爆款库

团队找创意的证据来源：被市场验证过的作品，每条一个 JSON 文件（合同 viral-reference，见 `../../团队/合同.md`），由市场研究采集和拆解。

- 文件名就是条目 id：`<平台缩写>-<采集日期>-<序号>.json`，例如 `xhs-20261015-01.json`、`dy-20261015-03.json`。
- 只收"异常表现"的作品：互动是作者近期同类作品中位数的 3 倍以上（`outlier_ratio`），大号的普通作品不算。
- 真看过视频才写画面和节奏结论（`media_reviewed: true`）；只看了标题、封面和数据的写 false。
- `observed`（事实和数据）、`inferred`（成功原因的推测）、`transferable`（可迁移的方法）分开写。
- 宁少勿滥：早期 10 条完整拆解，好过 100 条只有标题和点赞的记录。旧条目不删，过时的在 `observed` 里注明。
- 只记公开可见的内容；他人作品的抽帧和转写只用于分析，留在任务目录，不进这里、不用于发布。
