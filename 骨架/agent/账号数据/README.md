# 账号数据与分析

保存账号分析所需的原始资料、指标口径和正式报告；不承担发布执行或发布台账职责。观察时间、采集时间和整理时间分别说明。

- `原始资料/<平台>/<账号标识>/<采集日期_事项>/`：截图、导出或文字摘录及来源说明；已存在的记录不覆盖。无原始图片时如实标明。
- `分析/<日期_分析主题>/`：正式分析报告和必要整理数据、指标说明；跨平台报告只保存一份。尚无正式分析报告，不建空报告。
- `对标库.md`：定位研究用的对标账号和作品证据（定位 SOP 的 P04、P05），每条写查看日期。
- `../工作/<任务>/`：任务状态、草稿、计算脚本和检查过程，引用这里的输入与正式成果。
- `../log/`：操作摘要与任务导航，不重复维护数据。
- 数据来自本人提供或明确授权的只读来源；不自动周期采集，缺值不填零，旧快照不当实时事实。
