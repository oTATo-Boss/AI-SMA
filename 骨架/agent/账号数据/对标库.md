# 对标库

定位研究用的对标账号和作品证据，按 `../sop/账号定位与对标分析.md` 的 P04、P05 收集。只记公开能看到的内容，看不到的播放、留存、收入不补造；每条写查看日期。

- **同类**：身份、制作方式或变现目标和本账号相近，至少 5 个；不够就写明查过的平台、搜索词和结果。
- **机制参考**：类型不同，但增长或表达方式值得学，至少 3 个。
- 每个账号至少 2 条爆款（明显高于它常规水平的作品）和 1 条常规作品对比。没有作品级证据的账号只算线索，不能支撑结论。
- 标志性设定（固定角色、世界观、招牌梗）只研究不照搬。
