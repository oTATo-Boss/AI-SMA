# SOP · 新账号开工

刚部署的账号项目用这份流程：马上告诉本人怎么用、要准备什么、要回答哪些问题，再把回答写进规范。根目录 `AGENTS.md` 开头还有"新项目还没开工"时，不管本人先说什么，都从这里接着做：已经回复过的不重复，看第 2 节各位置还有没有"待填写"，接着问没答的。

## 1. 部署后马上回复

一条消息。开头一句说明项目建在哪个文件夹、账号名是什么（取自文件夹名，不对请本人说），然后分三块写，用短句，不贴文件内容。

**怎么用**
- 以后在这个文件夹打开 Claude Code 或 Codex，直接说要做什么，比如"做一条关于……的视频""给这条视频配封面和文案""看看上周的数据"。
- 动手前会先请你确认选题，再确认具体的脚本或分镜；你没回复就不动手。
- 做好的内容在 `交付/`，一篇一个文件夹（视频、封面、发布文案）。发布由你在 App 里完成，发出去的可以归档到 `发布内容/`。
- Logo、角色图等品牌素材放进 `固定资产/`，agent 只读不改。进度看 `agent/log/任务总览.md`。

**要准备的**
- 按环境检查结果写：刚部署就用部署脚本的输出，否则运行 `python3 agent/tools/环境检查/检查环境.py`。只列缺的工具和技能，写名称、用途和安装方法，说明本人确认后再装；都齐了就写"本机环境已齐"。登录和输入 Key 由本人操作。
- 用到再准备：RunningHub Key（AI 视频生成，付费）、HeyGen 登录（配乐音效）、ChatGPT 桌面 App（Claude 生图）。
- Chrome 个人资料：要让 agent 只读查看平台后台或研究对标账号时，在 Chrome 给这个账号建一个个人资料并登录平台，把资料名告诉 agent。现在没有也能开工。

**要你回答的问题**：第 2 节的 7 个问题按编号原样列出，说明可以一次答完，答不上来的写"先跳过"。

## 2. 问题和写入位置

| # | 问题 | 写到 |
|---|---|---|
| 1 | 这个账号是谁、主要发什么？一两句话就行。 | `../规范/账号信息.md` 第一、四节；`../规范/账号配置.yaml` 的 identity、content.topic_boundaries |
| 2 | 做这个账号想达到什么？比如涨粉、带自己的产品、做个人品牌、接商单。 | `../规范/账号配置.yaml` 的 project.goal；`../规范/定位与策略.md` 第 2 节 |
| 3 | 发在哪些平台？已经有账号的，给主页链接或账号号。 | `../规范/账号配置.yaml` 的 platforms；`../规范/账号信息.md` 第三节；`../附录/账号与主页.md` |
| 4 | 有没有要带的品牌、产品或作品？内容里能露出到什么程度？ | `../规范/账号信息.md` 第一、二节；`../规范/内容与交付.md` 第 1、5 节 |
| 5 | 你出不出镜、出不出声？要不要配音或旁白？ | `../规范/账号配置.yaml` 的 audio；`../规范/内容与交付.md` 第 2 节 |
| 6 | 主要怎么做内容：AI 生成视频、代码动效或界面演示、实拍剪辑、图文？可以多选。 | `../规范/账号配置.yaml` 的 content.production_routes；`../规范/内容与交付.md` 第 3 节 |
| 7 | 自主创作时，付费生成每条视频最多花多少（默认 500 RunningHub 币）？同意在这个范围内由 agent 自动提交吗？ | `../规范/账号配置.yaml` 的 autonomy.budget_per_video；同意的写进 `../tools/runninghub-minimax-h3/AGENTS.md` 的授权（本人原话和日期） |

## 3. 收到回答后

1. 把回答写进第 2 节的位置，替换对应的"待填写"。按本人的意思写，不编经历、数据或偏好；跳过的保留"待填写"。本人给了 Chrome 个人资料名，就替换各处的"待填写：Chrome 个人资料名"。
2. 运行 `python3 agent/tools/项目检查/检查.py`，写当天日志。
3. 回复本人：写进了哪些文件；还剩哪些"待填写"，不急的工作中再补；下一步建议做一轮定位：新号按 `账号定位与对标分析.md`，已有粉丝或历史内容的账号按 `账号转型与重启.md`。第 7 题没同意自动提交的，说明付费生成每次提交前都会先问，自主创作会因此停下来等。当前会话是部署前就开着的，提醒本人关掉重开一次，项目规则和写入保护才会自动加载。
4. 删掉根目录 `AGENTS.md` 开头"新项目还没开工"那一段。
