# 项目检查

改规则、改工具或项目维护结束前运行。只读，标准库，几秒内完成。

```bash
python3 agent/tools/项目检查/检查.py                                   # 在项目根目录运行
python3 agent/tools/项目检查/检查.py --write-baseline <快照.json>        # 维护开始前记下受保护目录
python3 agent/tools/项目检查/检查.py --baseline <快照.json> --json <报告.json>   # 维护结束后比较并留报告
```

| 检查 | 失败条件 |
|---|---|
| 规则文档链接 | 入口、规范、SOP、工具、附录等文档里的链接或路径指向不存在的文件（示例和占位路径跳过） |
| 任务记录 | 任何 task.json 校验出错 |
| 受保护目录 | 与快照相比，交付/、发布内容/、固定资产/ 有新增、删除或改动（给了 --baseline 时） |
| 密钥 | `agent/.env` 里的密钥值或 Bearer 令牌出现在任何文本文件中（只报告位置，不输出内容） |
| 配置一致性 | `规范/账号配置.yaml` 的交付文件名、时区与任务管理 `流程定义.json` 不一致 |

另外报告两项提示（不判失败）：启动和各任务路由需要阅读的字符数（按根目录 AGENTS.md 的路由表计算），以及在 3 个以上文件里重复出现的关键规则。快照和报告放当前维护任务的 检查/ 目录。
