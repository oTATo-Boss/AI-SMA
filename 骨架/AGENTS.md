# {{账号名}} · agent 入口

Claude、Codex 启动时自动加载本文件。所有 AI 助手统称 agent，共用这里的规则、工作区和记录，不按软件分工。细则见 `agent/规范/项目规则.md`，需要时再读。

> **新项目还没开工。** 不管本人先说什么，先按 `agent/sop/新账号开工.md` 带本人开工；开工完成后删掉这一段。

## 红线

1. **不发布、不互动。** 发布、评论、私信、点赞、关注由本人在 App 里完成，agent 只准备内容包。改账号资料、开通功能、同意协议、删除文件：先说明方案，本人确认后才做。
2. **只在 agent/ 里写。** `发布内容/`、`固定资产/` 只读，要用的素材复制到当前任务目录；不借软链接、硬链接或工具输出路径绕过。
3. **交付只增不改。** 完整交付先在任务目录做好并检查，再整份复制到 `交付/` 下的全新目录；已有交付不改、不删、不追加，修订也新建目录。
4. **付费任务不重复提交。** 付费生成服务只在对应工具规则写明的授权范围内使用，没写明持续授权的，每次提交前先问本人；每次提交立刻保存任务 ID，结果不明先查询，不盲目重提。
5. **密钥不外泄。** 密钥只从环境变量、`agent/.env` 或本机私有配置读取，不打印，不写进任何文件、日志、提示词或交付。
6. **确认绑定版本。** 内容制作前先由本人确认选题，再确认具体版本的脚本／分镜（图文为每页方案）；本人没回复就等待，不推断同意。本人直接指定的选题记下原话即可。
7. **方向先复述，定位先于选题。** 本人调整方向、定位或目标时，先按"保留／放弃／新增"复述：角色、人设、粉丝、风格等核心资产有歧义的逐项问清，目标附上保底、目标、冲刺三档和依据；本人确认后才写进规范。只有本人原话能标【已确认】，agent 的理解标【待确认】。定位没确认，不出具体选题。
8. **不串号。** 只用本账号的资料：不读其他账号的项目文件夹；客户端全局记忆、浏览器里其他个人资料和标签页中关于别的项目或账号的内容，不采用、不写进本项目。需要参考时先问本人。

## 开始工作

1. 看 `agent/log/任务总览.md`；接续任务读它的 `task.json`。
2. 按下表只读当前任务需要的文件，不通读历史资料和全部工程。
3. 需要接续的执行任务用 `agent/tools/任务管理/` 登记；问答和简单讨论不登记。
4. 用技能前查 `agent/SKILLS_INDEX.md`，并完整读该技能的 SKILL.md；制作路线只用 `agent/规范/账号配置.yaml` 里 production_routes 启用的。

## 记录与汇报

- 日志：`agent/log/YYYY-MM/YYYY-MM-DD.md`，北京时间，每次工作一行 `- HH:MM · agent · 事项 · 结果 · 相关文件`；写前先读当天文件末尾。
- 结论写回对应文件：方向 → 定位与策略，偏好与教训 → 偏好与经验，外部资料 → 外部知识，数据 → 账号数据，资产位置 → 附录。一件事只写一处，其他地方引用。
- 用中文汇报，已完成、失败、未验证分开说。工具成功不等于产物合格，技术检查不等于本人验收，交付不等于发布。
- 网页只读操作只用本机 Chrome 的「{{浏览器资料}}」个人资料，还没有资料名就先请本人建好；工具列出的其他资料和标签页不打开、不记录。不用内置浏览器，登录失效告诉本人，不自己输密码或扫码。
