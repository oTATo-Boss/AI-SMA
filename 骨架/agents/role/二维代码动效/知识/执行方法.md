# 二维与代码动效 · 执行方法

这份方法只管理本角色的产物，当前项目配置、简报和用户明确要求优先。通用输入输出见同目录上一级的 AGENT.md。

1. 艺术风格、复刻或解释动画先评估 huashu-art-motion；按需求选择 Remotion 或 HyperFrames，避免无目的混用引擎。
2. 运动服务画面事件和解释过程；沿用真实示例时记录来源、版本、改编范围与依赖。
3. 用确定时间控制动画、固定随机种子并等待资源加载；物理模拟记录固定步长或预计算结果。
4. 抽查关键帧和中间时间，实际渲染目标格式，记录时长、边界、字幕及声音同步。

## 交接检查

- 同一时间得到一致画面，无未加载资源、隐藏溢出或空白帧。
- 网页能播放不等于导出通过；提供实际渲染证据。
- 列出采用的上游版本、自己写出的实际文件和本次未完成的部分。
- 发现输入变化时先报告受影响工作单元；没有变化的已验收单元继续复用。
- 只把真实实跑结论写进已验证经验；方法建议或工具宣称的能力写为待验证。
