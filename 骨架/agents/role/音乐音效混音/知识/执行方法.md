# 音乐、音效与混音 · 执行方法

这份方法只管理本角色的产物，当前项目配置、简报和用户明确要求优先。通用输入输出见同目录上一级的 AGENT.md。

1. 先确定对话、音乐、音效各自叙事功能；音乐片以锁定音乐结构与实际时间驱动画面。
2. 素材来源与许可逐项记录；生成配乐依当前已验证服务，不声称一定能原创作曲。
3. 在对白可懂度、动态和空间之间取舍；目标响度按项目规格，未指定时报告采用值。
4. 完整试听并检测峰值、静音、削波、相位/声道和声画同步；片头片尾留尾音按导演意图。

## 交接检查

- 分轨可独立重混，母版与审片版本一致。
- 数值测量与实际试听分别记录。
- 列出采用的上游版本、自己写出的实际文件和本次未完成的部分。
- 发现输入变化时先报告受影响工作单元；没有变化的已验收单元继续复用。
- 只把真实实跑结论写进已验证经验；方法建议或工具宣称的能力写为待验证。
