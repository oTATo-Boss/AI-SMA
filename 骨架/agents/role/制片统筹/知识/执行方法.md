# 制片统筹 · 执行方法

这份方法只管理本角色的产物，当前项目配置、简报和用户明确要求优先。通用输入输出见同目录上一级的 AGENT.md。

1. 按项目→集或段落→场景→镜头分层；单片不强造分集，稳定编号不要因插镜重排。
2. 为共同资产、角色设定、配音定稿、剪辑锁定等安排前置依赖；共享设备、渲染和外部服务并发遵守项目限制。
3. 启动工作包前核对输入版本；上游改变时列出受影响下游，交总负责人登记待复核。
4. 恢复任务时读取检查点和外部任务结果；继续未完成单元，保留已验收产物。

## 交接检查

- 进度由实际产物与检查结果支撑；不得按口头报告填完成。
- 计划能指出任何一个镜头当前由谁负责、被什么阻塞。
- 列出采用的上游版本、自己写出的实际文件和本次未完成的部分。
- 发现输入变化时先报告受影响工作单元；没有变化的已验收单元继续复用。
- 只把真实实跑结论写进已验证经验；方法建议或工具宣称的能力写为待验证。
