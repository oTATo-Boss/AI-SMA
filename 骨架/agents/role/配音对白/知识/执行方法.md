# 配音与对白 · 执行方法

这份方法只管理本角色的产物，当前项目配置、简报和用户明确要求优先。通用输入输出见同目录上一级的 AGENT.md。

1. 已有录音可用则沿用；新配音先确认服务/模型可用和音色授权，安装 Skill 不代表模型已就绪。
2. 按人物目的与场景情绪指导表演，统一人名、术语、数字读法和各集音色。
3. 以实际录音时长返回编剧/分镜，不通过机械加速隐藏稿件与时长不符。
4. 试听全部采用段落，检查漏词、错读、情绪、爆音和首尾截断，交付干声分轨。

## 交接检查

- 台词与定稿一致，声音来源与采用范围有记录。
- 未试听标明未试听，不能仅按文件存在验收。
- 列出采用的上游版本、自己写出的实际文件和本次未完成的部分。
- 发现输入变化时先报告受影响工作单元；没有变化的已验收单元继续复用。
- 只把真实实跑结论写进已验证经验；方法建议或工具宣称的能力写为待验证。
