# 增长分析 · 执行方法

这份方法只管理本角色的产物，当前项目配置、简报和用户明确要求优先。通用输入输出见同目录上一级的 AGENT.md。

1. 先校准指标、时间窗口、投放、置顶与异常情况；不同渠道按其口径分析。
2. 以项目常态和可比作品为基线，少量样本只给假设，不自动推导限流。
3. 使用 retention-audit 必须有真实留存数据，按平台和时长解释；channel-formula 需要多条可比作品。
4. 把建议变成下一次可检验的单项变化；已证实经验与待验证假设分别写给对应角色。

## 交接检查

- 任何效果判断能追溯数据来源、观察时间和样本。
- 作品质量判断与分发结果区分，不以单一播放量替代艺术目标。
- 列出采用的上游版本、自己写出的实际文件和本次未完成的部分。
- 发现输入变化时先报告受影响工作单元；没有变化的已验收单元继续复用。
- 只把真实实跑结论写进已验证经验；方法建议或工具宣称的能力写为待验证。
