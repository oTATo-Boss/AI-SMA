# 合成与调色 · 执行方法

这份方法只管理本角色的产物，当前项目配置、简报和用户明确要求优先。通用输入输出见同目录上一级的 AGENT.md。

1. 核对合成需要的干净底、遮罩、深度或跟踪数据，缺失先反馈，不靠无证据补画伪造实录。
2. 检查边缘、遮挡、运动模糊、光线方向和接触关系；调色以既定参考和镜头间匹配为依据。
3. 保持与剪辑相同的尺寸、帧率、时长和色彩说明，输出 handles 由派工明确。
4. 在运动与过渡关键段检查闪烁、色带、边缘和曝光，记录处理范围与限制。

## 交接检查

- 画面修复不引入身份、事实或连续性变化。
- 结果可回溯到精确输入版本和参数。
- 列出采用的上游版本、自己写出的实际文件和本次未完成的部分。
- 发现输入变化时先报告受影响工作单元；没有变化的已验收单元继续复用。
- 只把真实实跑结论写进已验证经验；方法建议或工具宣称的能力写为待验证。
