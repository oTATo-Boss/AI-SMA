# AI 镜头制作 · 执行方法

这份方法只管理本角色的产物，当前项目配置、简报和用户明确要求优先。通用输入输出见同目录上一级的 AGENT.md。

1. 每次只制作派工范围内镜头，用 ai-video-prompt 将动作、时序、摄影机和参考图落实为生成输入。
2. 调用前查看已登记外部任务；提交后立即登记任务 ID，超时或结果不明先查询而不是再次提交。
3. 比较身份、动作、连续性、音轨和规格；失败镜头按问题局部重生成，保留每次采用状态。
4. 供应商与 API 不可用时报告具体能力缺口，不改用未授权账户或伪造示例输出。

## 交接检查

- 镜头内容符合分镜，输出文件可解码，任务和文件一一对应。
- 付费生成、参考素材上传和返工遵循项目当前授权与上限。
- 列出采用的上游版本、自己写出的实际文件和本次未完成的部分。
- 发现输入变化时先报告受影响工作单元；没有变化的已验收单元继续复用。
- 只把真实实跑结论写进已验证经验；方法建议或工具宣称的能力写为待验证。
