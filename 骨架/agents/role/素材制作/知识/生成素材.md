# AI 镜头执行与恢复

使用 asset-generation 整理参考、ai-video-prompt 编写镜头提示词，rh-minimax-h3 仅在该服务已安装、凭据可用并符合项目路线时使用。当前 provider 的真实能力优先于历史默认。

1. 核对分镜版本、角色资产和镜头前后状态，提示词中引用实际文件和清楚时序。
2. 提交前看已存在任务和输入指纹；提交后马上登记任务 ID。返回状态不明先查询，不开新批次绕过并发限制。
3. 凭据留在服务声明的本机私有位置或环境中；日志、回包和交付不得包含密钥。
4. 下载后检查容器、视频流、尺寸、时长和音轨；原始结果保留，放大不冒称原生分辨率。
5. 按时间码查看身份、数量、动作、空间、文字与声音。缺陷分为参考问题、提示问题、生成失败或可剪辑问题，定位后返工。
6. 每个采用镜头交出可用区间、限制、参考/提示词版本和真实检查；文件生成成功但内容失败不能交为合格镜头。

局部重生成仍遵循当前任务授权、并发和返工上限。无法满足时交回具体缺口，不改创意来掩盖失败。
