# 资料与事实核验 · 执行方法

这份方法只管理本角色的产物，当前项目配置、简报和用户明确要求优先。通用输入输出见同目录上一级的 AGENT.md。

1. 从台词、字幕、图表与视觉演示提取具体主张，给每项稳定编号。
2. 优先原始资料、官方文档、论文或用户真实产品资料；时效事实记录核验日期。
3. 区分原始事实、估算、观点、戏剧虚构与视觉比喻；比喻不能在成片里变成事实断言。
4. 结论带适用范围和证据引用；证据冲突保留双方并建议如何改写或补证。

## 交接检查

- 引用确实支持关联主张；没有看过的资料不写已核验。
- 数字、单位、时间、因果与产品功能在脚本和画面间一致。
- 列出采用的上游版本、自己写出的实际文件和本次未完成的部分。
- 发现输入变化时先报告受影响工作单元；没有变化的已验收单元继续复用。
- 只把真实实跑结论写进已验证经验；方法建议或工具宣称的能力写为待验证。
