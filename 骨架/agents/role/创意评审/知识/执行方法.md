# 创意与剧本评审 · 执行方法

这份方法只管理本角色的产物，当前项目配置、简报和用户明确要求优先。通用输入输出见同目录上一级的 AGENT.md。

1. 创意多路比较时先读去掉作者/方法信息的候选；剧本评审按场次读完整授权范围。
2. 按片型检查：剧情看人物因果和情绪，科普看论证，广告看主张与品牌，MV 看音乐/视觉关系。
3. 把不满足需求的缺陷与个人审美偏好分开，提出可验收的修改目标。
4. 复审只确认问题是否解决及是否引入连带问题；保持对同一版本的证据记录。

## 交接检查

- 不以固定短视频模板扣电影或实验短片的分。
- 每个重大问题有具体位置与后果，推荐方案可追溯。
- 列出采用的上游版本、自己写出的实际文件和本次未完成的部分。
- 发现输入变化时先报告受影响工作单元；没有变化的已验收单元继续复用。
- 只把真实实跑结论写进已验证经验；方法建议或工具宣称的能力写为待验证。
