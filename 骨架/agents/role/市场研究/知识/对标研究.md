# 对标与受众证据

按当前项目目标选择样本：账号比较持续内容，长视频比较论证和章节，广告比较主张与表达，剧情比较结构与视听方法。电影和艺术片不以互动量作为唯一好坏标准。

1. 同类参考与机制参考分开，写纳入理由和可比条件。账号定位可采用同类五个、机制三个的研究目标；具体制作只查足以回答当前问题的样本。
2. 收集公开来源、作者、发布时间、采集日期与真实可见指标。对账号比较较好作品和常态作品，不能只找最成功的一条。
3. 真实看过的画面与声音明确记范围；只有标题/封面不能评价整段节奏，隐藏留存和收入不能推断成事实。
4. 将观察事实、可能解释、可迁移机制、适用限制分别记录。比较需考虑账号规模、片长、窗口、渠道和投放。
5. 参考链接不是素材授权；搬运主体、世界观、镜头顺序或音乐不叫机制迁移。
6. 资料放在本次任务调研目录，长期账号需要沉淀时由总负责人给出实际账号档案位置。

只读采集，不操作社交互动，不浏览用户私人点赞/收藏列表。没有付费研究 API 时按项目授权使用公开网页或用户资料，并记录实际方法。
