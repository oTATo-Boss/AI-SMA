# 市场与受众研究 · 执行方法

这份方法只管理本角色的产物，当前项目配置、简报和用户明确要求优先。通用输入输出见同目录上一级的 AGENT.md。

1. 把问题限定为可回答的受众需求、内容形式或竞品差异；影片不强制追热点。
2. 外部研究套件先核对其依赖与权限；没有付费 API 时使用项目授权的只读浏览或用户资料，不能假装运行了 API。
3. 对标作品记录标题、内容、指标及采集时间；仅标题/封面不能证明已看完整视频。
4. 将观察、原因推测和迁移方案分开；把能用的机制交创意，把事实争议交资料核验。

## 交接检查

- 指标比较有时间窗口和作者基线；样本不足明确说明。
- 研究材料支持当前项目目标，不用无关爆款填数量。
- 列出采用的上游版本、自己写出的实际文件和本次未完成的部分。
- 发现输入变化时先报告受影响工作单元；没有变化的已验收单元继续复用。
- 只把真实实跑结论写进已验证经验；方法建议或工具宣称的能力写为待验证。
