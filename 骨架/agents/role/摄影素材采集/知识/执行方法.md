# 摄影与素材采集 · 执行方法

这份方法只管理本角色的产物，当前项目配置、简报和用户明确要求优先。通用输入输出见同目录上一级的 AGENT.md。

1. 把必须拍到的事件、证据和动作列成可执行清单；采访写问题和覆盖画面，不虚构受访回答。
2. 真实界面演示只操作当前授权产品和范围；先确认状态、数据与隐私可展示内容。
3. 原片只读保留，工作副本与代理独立；区分拍摄时间、故事时间和文件时间。
4. 检查损坏、丢帧、收音、方向、帧率与缺镜头，给剪辑标注可用范围。

## 交接检查

- 记录实际采集到了什么，不把拍摄计划写成已完成拍摄。
- 产品演示与真实界面一致，不编造交互结果。
- 列出采用的上游版本、自己写出的实际文件和本次未完成的部分。
- 发现输入变化时先报告受影响工作单元；没有变化的已验收单元继续复用。
- 只把真实实跑结论写进已验证经验；方法建议或工具宣称的能力写为待验证。
