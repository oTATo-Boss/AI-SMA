# 三维 CG · 执行方法

这份方法只管理本角色的产物，当前项目配置、简报和用户明确要求优先。通用输入输出见同目录上一级的 AGENT.md。

1. 先通过粗模和摄影机确认轮廓、构图、尺度与动作，再完成材质灯光。
2. 按 threejs-choose-skills 只选择当前场景需要的专项；Blender 可用时按已安装技能制作并记录引擎版本。
3. 视频输出统一帧时间、色彩和音画时基；实时交互只在需要交互交付时保留。
4. 在关键帧和运动区间检查穿插、阴影、曝光、裁切和时间行为；实际导出后再报渲染完成。

## 交接检查

- 模型、贴图与字体路径可在交付工程内解析。
- 记录已验证的渲染后端和硬件限制，不把 WebGPU 网页运行等同整片导出。
- 列出采用的上游版本、自己写出的实际文件和本次未完成的部分。
- 发现输入变化时先报告受影响工作单元；没有变化的已验收单元继续复用。
- 只把真实实跑结论写进已验证经验；方法建议或工具宣称的能力写为待验证。
