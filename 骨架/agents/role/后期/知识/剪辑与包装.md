# 剪辑执行

post-producer 负责剪辑。标题、封面和打包交 delivery-producer；声音、字幕、合成角色存在时按对应产物接口协作。

1. 先读导演方案、剧本和实际素材，列可用镜头与缺镜，不按文件顺序机械拼接。
2. 切点服务行动、信息、情绪和音乐。自动去停顿或去口误仅用于匹配的口播素材，剧情停顿不默认删。
3. 原始素材只读，时间线记录源文件、版本、入出点、速度和裁切。任何替代镜头说明原因及剧情/连续性影响。
4. 工作版有清楚版本号与时间基准；画面变化列明受影响时间范围，使声音和字幕能准确跟进。
5. 检测导出文件可完整解码、尺寸/帧率/时长/音轨正确，再实际看片头、切点、运动、片尾及授权范围。
6. 审片退回只修指派问题；修改可能影响其他镜头时报告。新成片生成新版本和哈希。

交剪辑文件或可重现脚本、工作片与剪辑映射；自己的自检不代替最终审片。
