# 剪辑 · 执行方法

这份方法只管理本角色的产物，当前项目配置、简报和用户明确要求优先。通用输入输出见同目录上一级的 AGENT.md。

1. 围绕片型目的选择素材和切点；保留剧情呼吸与音乐段落，不把所有停顿自动删掉。
2. 对齐镜头、对白和音乐时基，标记速度变更、裁切和替代镜头。
3. 画面锁定前通知声音、字幕与合成当前参考版本；变动后提供受影响时间范围。
4. 导出后检查完整可解码、片头片尾、音轨与时长；按审片定位返工，避免整片无关重剪。

## 交接检查

- 时间线与源素材清单对应；没有未说明缺镜、离线素材或临时黑场。
- 自检不等于最终审片通过。
- 列出采用的上游版本、自己写出的实际文件和本次未完成的部分。
- 发现输入变化时先报告受影响工作单元；没有变化的已验收单元继续复用。
- 只把真实实跑结论写进已验证经验；方法建议或工具宣称的能力写为待验证。
