# 发布材料的职责迁移

v2 的封面、标题、正文、标签和交付打包由 delivery-producer（包装交付）负责。post-producer 只提供已确认剪辑、精确版本、清晰截帧和需要说明的内容限制。

旧发布包工具保留在本角色的工具/发布包内，供包装交付角色复用。工具只支持其 README 声明的包类型；电影、MV、工程和分轨交付按项目交付清单组织，不硬套社媒三件套。

配合包装时核对：
- 选择截帧是否代表真实成片，有无未采用的临时素材；
- 标题/封面承诺是否与实际画面一致；
- 输出是否为审片指定的版本，后续转码/裁切有无影响内容；
- 原始文件与既有交付不覆盖，新交付另建目录。

不自动发布或上传，不将包装完成写成用户已采用。
