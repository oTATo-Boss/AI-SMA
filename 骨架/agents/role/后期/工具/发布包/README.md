# 发布包：三文件交付包整理与检查

把已验收的成片、封面和发布文案整理成一个交付文件夹，并做技术检查。后期的工具。规格见 `agents/账号/账号配置.yaml`（cover、delivery），文案格式见 `agents/账号/内容与交付.md` 第 4 节。离线运行，不生成、不压缩、不上传、不发布。

## 用法（在项目根目录运行，依赖 ffmpeg、ffprobe）

```bash
python3 agents/role/后期/工具/发布包/package_post.py --video 工作中的成片.mp4 --cover 封面.png --copy 发布文案.txt --out agents/工作/<任务>/交付暂存
```

- 文件夹名是"整理时的北京时间_标题"，可用 `--timestamp YYYYMMDD_HHMM` 指定；目标已存在就报错，不覆盖。
- 检查：TXT 依次有标题、正文、标签三段；封面是真 PNG 且精确 3:4；视频是 MP4、有视频流、能完整解码；复制后视频哈希与源文件一致；目录里只有三件文件。
- 检查报告 `<文件夹名>.qa.json` 写在交付暂存目录，不进交付包。
- 脚本不检查审美、声音内容和标签热度，这些要另外实际检查。

## 之后

1. 后期：`python3 agents/role/总负责人/工具/任务管理/任务管理.py check-package agents/工作/<任务>/交付暂存/<文件夹> --kind social-video --new-name <文件夹>`，把包的位置交给总负责人。
2. 总负责人一条命令整份复制到交付，目标已存在就停下换新名称：`[ ! -e 交付/<文件夹> ] && cp -R agents/工作/<任务>/交付暂存/<文件夹> 交付/<文件夹>`
3. 总负责人用任务管理工具的 `delivery` 登记，等本人验收。
