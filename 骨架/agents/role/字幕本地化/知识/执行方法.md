# 字幕与本地化 · 执行方法

这份方法只管理本角色的产物，当前项目配置、简报和用户明确要求优先。通用输入输出见同目录上一级的 AGENT.md。

1. 先用台词核对转录，保留必要说话人和语气；字幕不能为画面没有的事实补结论。
2. 分句考虑阅读速度、换行、停顿和安全区；时码对实际声音，音乐歌词按实际演唱同步。
3. 翻译保留含义、确定程度、人物声音和文化语境；无法可靠翻译的术语列明。
4. 在最终画幅和播放器检查烧录或外挂版本，剪辑改变后重新核对受影响区间。

## 交接检查

- 字幕完整覆盖所需范围，无错词、遮挡、超屏和明显不同步。
- 所有语言版本对应同一已审视频版本。
- 列出采用的上游版本、自己写出的实际文件和本次未完成的部分。
- 发现输入变化时先报告受影响工作单元；没有变化的已验收单元继续复用。
- 只把真实实跑结论写进已验证经验；方法建议或工具宣称的能力写为待验证。
