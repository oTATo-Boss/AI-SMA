# 按项目类型开工

收到一句话部署后先核实实际装配结果，继续担任主对话总负责人。已从用户句子取得的信息不要重复问。

## 部署后说明

用一条简短消息说明项目类型、形态、已启用制作路线、交付位置和如何提需求。安装回执未验证、工具缺失、登录待完成、客户端待重载分别说明；仅“装配成功”不能写“可制作”。

技能和必要工具由部署智能体按公开来源与当前系统安装并验证。不要把全部安装命令甩回用户。密钥和账户登录由用户完成，不写入模板、技能包或交付。

客户端需要信任目录或重载时据实际结果提示，不保证所有系统已被实测。无法使用子 agent 时可按 self 顺序代行，独立审查状态如实保留。

## 共同简报

只补当前制作所需的缺项：做什么及目的、给谁看、片长或集数、制作路线、已有素材/产品/故事、风格与禁用项、声音、画幅和交付要求。记录来源与确定程度；用户略过的项保留待定，不能补成事实。

| 项目类型 | 额外必须明确的事项 |
|---|---|
| 社媒账号 | 身份、目标、平台、品牌露出、出镜与声音、持续制作方式；先定位后具体选题 |
| 长视频与纪录 | 论点/问题、资料来源、章节、真实访谈/实拍素材与引用范围 |
| 科普 | 核心解释、准确性边界、观众知识水平、证据与可视化方式 |
| 广告 | 品牌/产品、核心主张、可证实依据、行动目标与交付版本 |
| Launch | 真实产品界面、要演示的功能与结果、公开范围、发布用途 |
| 剧情短片/电影 | 故事概念、主要人物、情绪与结局、场景/演员或生成资产限制 |
| 连续剧情 | 总纲、集数/单集范围、主要人物弧线、跨集设定与本次制作集数 |
| MV | 已授权歌曲或音乐来源、采用版本、叙事/表演/歌词/视觉化形式 |
| 动效/视觉实验 | 视觉目标、运动机制、时长、声音、可编辑工程及播放/视频交付 |

## 简报落地

新项目将共同事实写到项目档案和配置，任务范围写入对应简报。账号专属资料只在社媒模板实际存在的账号档案中维护；非账号项目不创建定位、选题池或后台数据要求。

用户要求先讨论、先脚本或先确认时，停在明确边界。已有足够简报的制作请求可进入被授权阶段，不能把每次窄任务都升级成完整开工访谈。

## 完成条件

必需技能与运行依赖有验证证据，使用的服务可用；当前制作所需事实与规格明确，必要的方向选择已确认。账号还需定位确认和内容策略；单片/系列按其简报准备度判断。把阶段改成已开工并记录仍可后补的非阻塞项。
