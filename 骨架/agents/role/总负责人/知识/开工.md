# 开工

刚部署的账号项目由总负责人用这份流程带本人开工：马上告诉本人怎么用、要准备什么、要回答哪些问题，再把回答写进账号档案，然后做一轮定位。`agents/账号/账号配置.yaml` 的 stage 是"开工中"时，不管本人先说什么，都从这里接着做：已经回复过的不重复，看第 2 节各位置还有没有"待填写"，接着问没答的。

## 1. 部署后马上回复

一条消息。开头一句说明项目建在哪个文件夹、账号名是什么（取自文件夹名，不对请本人说），然后分三块写，用短句，不贴文件内容。

**怎么用**
- 以后在这个文件夹打开 Codex（或 Claude Code），直接说要做什么，比如"做一条关于……的视频""给这条视频配封面和文案""看看上周的数据"。
- 你只和总负责人说话，调研、创意、制作、审片由团队里的子智能体完成。开工阶段（定方向）会问你；之后做内容中途不找你，做好放进 `交付/`，你验收就行。
- 做好的内容在 `交付/`，一篇一个文件夹（视频、封面、发布文案）。发布由你在 App 里完成，发出去的可以归档到 `发布内容/`。
- Logo、角色图等品牌素材放进 `固定资产/`，智能体只读不改。进度看 `agents/工作/任务总览.md`。

**要准备的**
- 在 Codex 里信任这个文件夹，然后新开一个对话。不信任的话，Codex 会忽略项目里的子智能体和写入保护；第一次还要在 Codex 里批准一次项目自带的写入保护，它会拦住误写固定资产、发布内容和已有交付。用 Claude Code 的，关掉重开一次，并把权限模式设成自动接受编辑（或 auto），不然子智能体每次写文件、运行命令都会停下来问你；写入保护照样生效。两个软件里需要联网的命令（比如调 RunningHub）都可能要你点一次批准。
- 按环境检查结果写：刚部署就用部署脚本的输出，否则运行 `python3 agents/公共/工具/环境检查/检查环境.py`。只列缺的工具和技能，写名称、用途和安装方法，说明本人确认后再装；都齐了就写"本机环境已齐"。登录和输入 Key 由本人操作。
- 用到再准备：RunningHub Key（AI 视频生成，付费）、HeyGen 登录（配乐音效）、ChatGPT 桌面 App（Claude 生图）。
- Chrome 个人资料：要让智能体只读查看平台后台或研究对标账号时，在 Chrome 给这个账号建一个个人资料并登录平台，把资料名告诉总负责人。现在没有也能开工。

**要你回答的问题**：第 2 节的 6 个问题按编号原样列出，说明可以一次答完，答不上来的写"先跳过"。

## 2. 问题和写入位置

| # | 问题 | 写到 |
|---|---|---|
| 1 | 这个账号是谁、主要发什么？一两句话就行。 | `agents/账号/账号信息.md` 第一、四节；`agents/账号/账号配置.yaml` 的 identity、content.topic_boundaries |
| 2 | 做这个账号想达到什么？比如涨粉、带自己的产品、做个人品牌、接商单。 | `agents/账号/账号配置.yaml` 的 project.goal；`agents/账号/定位与策略.md` 第 2 节 |
| 3 | 发在哪些平台？已经有账号的，给主页链接或账号号。 | `agents/账号/账号配置.yaml` 的 platforms；`agents/账号/账号信息.md` 第三节；`agents/账号/附录/账号与主页.md` |
| 4 | 有没有要带的品牌、产品或作品？内容里能露出到什么程度？ | `agents/账号/账号信息.md` 第一、二节；`agents/账号/内容与交付.md` 第 1、5 节 |
| 5 | 你出不出镜、出不出声？要不要配音或旁白？ | `agents/账号/账号配置.yaml` 的 audio；`agents/账号/内容与交付.md` 第 2 节 |
| 6 | 主要怎么做内容：AI 生成视频、代码动效或界面演示、实拍剪辑、图文？可以多选。 | `agents/账号/账号配置.yaml` 的 content.production_routes；`agents/账号/内容与交付.md` 第 3 节 |

## 3. 收到回答后

1. 把回答写进第 2 节的位置，替换对应的"待填写"。按本人的意思写，不编经历、数据或偏好；跳过的保留"待填写"。本人给了 Chrome 个人资料名，就写进 `agents/账号/账号配置.yaml` 的 browser_profile。
2. 运行 `python3 agents/公共/工具/项目检查/检查.py`，写当天日志。
3. 回复本人：写进了哪些文件；还剩哪些"待填写"，不急的工作中再补；下一步做一轮定位：新号按 `agents/role/总负责人/知识/定位与对标.md`，已有粉丝或历史内容的账号按 `agents/role/总负责人/知识/转型与重启.md`。

## 4. 开工完成

定位方案经本人确认并写回 `agents/账号/定位与策略.md`（定位状态"已确认"），内容策略和第一批候选选题写进 `agents/账号/选题池.md` 之后，把 `agents/账号/账号配置.yaml` 的 stage 改成"已开工"，写日志，告诉本人：以后说"做一条视频"就行，团队自己完成，中途不找你。
