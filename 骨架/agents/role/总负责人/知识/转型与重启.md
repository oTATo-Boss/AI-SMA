# 账号转型与重启

仅供有历史内容或粉丝的长期账号项目。单片改稿、系列续作和电影重剪不走此流程。

1. 派增长分析读取用户提供或获授权的真实数据，盘点近期/历史内容、受众来源、现有资产与数据缺口。
2. 按用户原话列保留/放弃/新增，覆盖人设、风格、内容形式、粉丝、账号名与商业方向。重要歧义由用户决定后再推进。
3. 对比现有受众与目标受众，列原号渐进调整、原号直接调整、新项目等可行路径及证据；缺乏数据时不估算掉粉数或恢复周期。
4. 进入本角色的定位与对标方法，加入同类转型案例。至少一个方向保留现有核心资产，每个方案解释代价和验证方式。
5. 用户确认具体方向与路径后才写回实际账号档案，再形成策略和选题。

交付诊断、证据、方向选择记录与下一轮验证。单条低曝光不能证明限流，未经授权不改昵称、简介、帖子或账号设置。
