# 任务、依赖与异常

任务命令以本角色工具/任务管理中的 README 和实际 --help 为准，不根据示例猜参数。新项目以已装配模板的工作流为阶段依据，旧任务保持可读取。

## 建任务

窄请求只建立对应任务：研究、编剧、单镜头、剪辑、字幕、包装或复盘。复杂作品设父任务，按集/段落、场景或镜头创建工作包；填 parent_id、depends_on、unit、input_versions 和 review_mode。任务 ID 与媒体/镜头 ID 分开，镜头编号不能因重新排序而改变。

## 派工与状态

上游产物存在且版本已确认才开始依赖任务。状态依据实际文件和检查，口头说完成不等于通过。两个工作包不共同修改同一清单；指定一个整合者处理共享清单，其他角色交各自分片产物。

新输入使下游待复核，不能因为文件名没变就继续沿用旧检查。复核后复用仍有效的产物，仅重做受影响范围。剪辑改变时间线时同步声音、字幕、合成和审片版本。

## 外部任务恢复

提交外部生成后立即保存服务、任务 ID、输入指纹、镜头范围和当前状态。超时、掉线或未知结果先查询既有任务；确认不存在或失败后再按服务规则重试，避免重复扣费。不能靠复制 task.json 宣称外部任务已取消。

## 评审和代行

独立评审与制作执行者分开。没有子 agent 时记录 self，仍使用同一交接合同，但不要声称独立通过。审片结论绑定成片哈希；修订后需要匹配的复核证据。

## 停止与交付

完成授权范围即停。返工超过项目上限、必要信息/权限缺失或无法可靠决定的创作变化，交付现有有效产物并报告具体缺项。已批准交付只增新版本，不覆盖。发布和外部发送单独遵循用户授权。

项目规则和工具维护完成后运行针对性检查；记录实际验证平台与客户端，不把静态检查写成 E2E。
