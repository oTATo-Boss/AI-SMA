# 总负责人 · 执行方法

这份方法只管理本角色的产物，当前项目配置、简报和用户明确要求优先。通用输入输出见同目录上一级的 AGENT.md。

1. 先识别长期账号、单片或系列，再按项目配置加载对应工作流；只做用户请求覆盖的阶段。
2. 派工必须写角色、工作单元、上游版本、输出路径、验收条件和可改范围；同一清单指定一个整合者。
3. 按依赖安排独立工作包并行，默认最多 3 个；保留已知外部任务 ID，状态不明先查询。
4. 返工只影响相关镜头和其依赖；达到配置的返工上限后报告具体剩余问题。

## 交接检查

- 未安装或未验证的必需技能列为阻塞，不用删掉技能名伪装就绪。
- 制作、自检、独立评审、用户采用分别记录。
- 列出采用的上游版本、自己写出的实际文件和本次未完成的部分。
- 发现输入变化时先报告受影响工作单元；没有变化的已验收单元继续复用。
- 只把真实实跑结论写进已验证经验；方法建议或工具宣称的能力写为待验证。
