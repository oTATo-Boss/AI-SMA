# 账号定位与对标

仅供长期账号项目使用；单片广告、电影、MV 和科普制作不以账号定位为前置。先从已部署项目档案读取用户目标、账号事实、偏好和现行策略，所有写回位置由实际项目目录确定。

顺序：诊断 → 对标证据 → 至少三个可比较方向 → 用户确认 → 内容策略 → 选题。用户已确认的方向直接作为约束，不重复整套定位。研究报告本身不授权改定位。

1. 明确此次是研究、局部修正还是获准变更。方向调整先按保留/放弃/新增复述，歧义影响角色、人设或商业路径时才询问。
2. 盘点用户已证实的条件、资产、目标和不做的内容；旧粉丝、收入和产品快照标日期，未知项不估造。
3. 派市场研究先看同类，再找机制参考。通常同类五个、机制参考三个，每个至少两条较好作品与一条常态作品；搜不到就给查过的范围和限制，不能为凑数纳入无关账号。
4. 事实、推测、可迁移机制分开。每个定位假设注明支持、削弱或未知的证据，缺证据时只做会影响选择的定向补充。
5. 至少三方向中保留一个贴近现有资产的方案；分别写受众、价值、差异、支柱、形式、成本和风险。有增长目标时给有依据的分档，不保证收入或增速。
6. 用户选定后，将方案版本与原话登记，再写回账号策略。未确认不出具体选题，也不改变账号设置。
7. 内容策略和候选选题关联已确认定位；候选不等于制作授权。账号已开工后，当前请求覆盖制作即可按团队流程推进，不再逐项重复确认。

使用 social-media-router、content-planning；真实后台分析交增长分析。研究来源和私有账号事实留在当前项目，经验不串号。
