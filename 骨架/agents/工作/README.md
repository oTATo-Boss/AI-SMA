# 工作 · 任务和日志

每个任务一个目录 `<时间>_<任务名>/`：当前状态只维护在 task.json，变更历史在运行记录.jsonl，各智能体的产物按 `agents/公共/合同.md` 放进对应子目录（调研、创意、方案、工程、产物、检查、交付暂存、复盘），用到才建。归属和权限以 [规则](../公共/规则.md) 为准；正式账号分析报告归 `agents/账号/数据/`，过程和计算脚本留在任务目录。

- [任务总览](任务总览.md)：任务管理工具生成，不手改。
- [日志](日志/README.md)：总负责人的工作日志。
- 任务命令见 [任务管理](../role/总负责人/工具/任务管理/README.md)。task.json 只通过任务管理工具写，不另建全局运行状态。
