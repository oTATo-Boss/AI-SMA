# 账号 · 账号档案

这个账号的事实、方向、规范和数据，所有智能体共用。每份文件只维护自己的职责，按需读取，不用通读。事实和方向放在这里，不等于都是强制规则；某个智能体自己的经验写在它的 `记忆/`。

| 文件 | 唯一职责 |
|---|---|
| [账号配置](../项目/项目配置.yaml) | 账号名、开工状态、平台、制作路线、规格参数、生成默认值、交付命名、团队上限、Chrome 资料名；也是 social-media 技能读取的项目配置 |
| [账号信息](账号信息.md) | 本人、品牌、产品和账号的事实 |
| [定位与策略](定位与策略.md) | 定位（确认状态）、目标、受众、内容体系、变现、测试和信号 |
| [内容与交付](内容与交付.md) | 品牌、声音、制作、包装、分发检查和验收标准 |
| [偏好](偏好.md) | 本人对整个账号的偏好、审美反馈和教训 |
| [选题池](选题池.md) | 候选想法、来源和已立项任务的链接 |
| [外部知识](外部知识.md) | 有出处和日期的外部资料 |
| [对标库](对标库.md) | 定位研究用的对标账号和作品证据 |
| [爆款库](爆款库/README.md) | 被市场验证过的作品，一条一个 JSON |
| [数据](数据/README.md) | 本账号的原始数据和正式分析报告 |
| [附录](附录/README.md) | 本人的产品、仓库、账号主页、素材分别在哪 |
| [历史资料](历史资料/README.md) | 停用资料，只用于追溯 |

谁来写：开工阶段由总负责人带本人填写；方向、定位、目标的改动按入口红线 7 先复述，等本人确认。爆款库和对标库由市场研究写，数据由增长分析写，其余由总负责人维护。细则见 `agents/公共/规则.md`。
