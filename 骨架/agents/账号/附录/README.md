# 附录 · 本人资产与来源

这里记本人的项目、产品、代码仓库、账号、作品和素材分别在哪里，让任何智能体不靠对话记忆也能找到。规则在项目根目录 `AGENTS.md`，方向在 `agents/账号/定位与策略.md`，这里只记"在哪里、是什么、能不能用"。

| 文件 | 内容 |
|---|---|
| `本人资产地图.md` | 本机各个文件夹是什么、智能体能不能用 |
| `产品与代码仓库.md` | GitHub 账号；本人产品、其他个人项目和 Skill 仓库：网址、本地路径、GitHub、技术栈、现状 |
| `账号与主页.md` | 各平台账号、账号号、主页链接、用途 |
| `作品与素材来源.md` | 品牌资产、角色资产、素材库、提示词库、技能源、工作流、作品集、历史作品 |

## 维护规则（必须遵守，防止信息壁垒）

- 一有新信息当场更新：本人做了新产品或工具、改了网址或仓库、开了新账号、有了新作品或素材库、文件夹搬了家、项目状态变了（上线、收费、停更）。更新对应文件，并告诉总负责人在当天日志里记一条（子智能体同时记进自己的记录）
- 本人在对话里随口提到的新项目、新资源、新链接，也要记进来；没核实的标「待核实」
- 开工时发现这里写的路径或状态和实际不符，就地更正，并告诉总负责人在当天日志里说明
- 产品现状如果影响定位或变现，同步改 `agents/账号/账号信息.md` 和 `agents/账号/定位与策略.md`
- 只记位置、用途和公开信息，不复制内容；不记身份证号、银行卡、住址、电话、密钥等敏感信息
- 每个文件顶部写"最后核对"日期
