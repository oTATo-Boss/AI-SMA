# 项目团队

本项目由总负责人协调已装配的专业角色。实际角色、片型、路线和技能集合见 `项目/装配清单.json`，每个角色的职责与技能在 `role/` 对应目录。不要把角色库里的所有角色同时派出。

- 项目事实与交付规格：`项目/项目配置.yaml`。
- 技能安装与能力状态：`项目/安装回执.json`、`公共/技能安装.md`。
- 当前工作与检查点：`工作/任务总览.md` 以及各任务的 task.json。
- 交接产物：`公共/合同.md`。
- 共同规则：项目根入口和 `公共/规则.md`。

一个角色负责一个明确的产物或审查结论；相同角色可按独立镜头/场景分组执行。不同角色各写自己的文件，共享清单由派工指定的整合者更新。单 agent 顺序代行使用同一合同，并记录自检身份。

账号模板额外包含账号档案；其他项目不需要账号定位、选题池或后台数据。技能实体位于本机共享库，项目内索引绑定真实入口；完整技能未安装前不得把仅有名称的配置当成可用能力。
