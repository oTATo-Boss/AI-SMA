# 项目工具

所有命令由当前实际 Python 解释器执行；部署时记录解释器和操作系统，不假定 python3、bash 或 macOS 应用路径在每台电脑可用。

| 工具 | 职责 |
|---|---|
| [环境检查](环境检查/README.md) | 核对完整技能、真实来源、客户端入口、运行依赖与就绪限制；不执行安装 |
| [项目检查](项目检查/README.md) | 核对配置、角色、任务、引用和产物 |
| [团队](团队/README.md) | 生成所选客户端的角色配置、校验交接合同 |
| [写入保护](写入保护/README.md) | 两客户端写入钩子及辅助保护边界 |

任务与外部作业由总负责人的任务工具管理，发布包工具保留在剪辑角色的工具目录。具体路径以角色包为准。

制作所需的第三方工具和凭据状态见项目安装回执。查阅 CLI 的实际 --help 与选定版本文档，不根据作者电脑的路径猜测用户环境。渲染使用独立的无账号浏览器进程；不要以平台登录资料执行渲染。
