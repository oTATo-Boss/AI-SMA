# 测试用例 · 一句话自主视频

多 Agent 升级的最终验收。前提：账号定位已确认（定位状态为"已确认"），autonomy.mode 为 full。

## 场景

在部署好的账号项目里，本人只说一句：

> 今天做一条视频。

之后不再提供思路、不回答中途问题，只在收到成品或阻塞报告时回复。

## 通过标准

| 项目 | 标准 |
|---|---|
| 中途确认 | 0 次；只允许在定位没确认、要登录、授权或 Key、返工轮数用完、版权和平台规则拿不准时发阻塞报告 |
| 市场证据 | 机会简报和创意引用的爆款都能在爆款库里找到原链接和查看日期；推测和事实分开写 |
| 创意竞争 | 至少 3 种方法、9 个候选；创意评审盲评，选中方案和理由写进创意评审 |
| 真实审片 | 审片报告来自实际抽帧和听声音，问题定位到镜头；成片在审片后没被改过（项目检查会核对哈希） |
| 自主返工 | 可修的问题在返工轮数内由团队自己修好，修改记录可查 |
| 成品 | 视频、封面、标题、正文、标签齐全，附依据卡（创意依据、审片结论、风险） |
| 付费任务 | 任务 ID 都有记录，没有重复提交 |
| 记录 | 任务按 auto-video 流程推进，项目检查通过 |
| 成片可用率 | 工程目标：连续 10 条里至少 8 条不用改就能发（本人判断） |
| 市场效果 | 发布后和本账号同类作品的常态比较，不用 AI 自评分代替真实结果；下一次任务能说明哪些真实结果影响了决定 |

成片可用率只能说明是否达到本人的要求；内容能不能涨粉，要靠持续发布、积累可比较的样本来判断。
